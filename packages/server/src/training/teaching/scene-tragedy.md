# 悲剧告别

## 本节目标

- **克制**胜过嚎哭：细节胜过大段哭喊。
- 写**失去**的具体（空椅、未送出的物、习惯动作落空）。
- 余波：安静、麻木、反常平静。
- 避免狗血台词与「命运啊」抒情。

## 核心概念

悲剧告别让读者**心里一沉**，不必全员流泪。网文常用：死别、永诀、不得不走、认错人为尸体。

力量来自**日常细节的断裂**：还习惯倒两碗茶，才想起只有一碗了。

## 怎么做

1. **选一个具体物**承载关系（刀、帕、糖）。
2. **少写「悲伤」**，写动作滞涩。
3. **对话宜短**，或无言。
4. **写一件小事做完**（关门、收尸、烧信）。
5. **留空白**，不解释所有感情。

**检查清单**

- [ ] 是否克制？
- [ ] 是否有具体细节？
- [ ] 是否狗血堆砌？

## 正反例

| 差 | 好 |
| --- | --- |
| 他悲痛欲绝，哭喊天地。 | 甲把乙的手从刀柄上掰开，掰了两次才成。袖里滚出一颗糖，化了一半。甲攥住，没吃。 |
| 场面非常感人，读者都哭了。 | 城门关到一半，乙还在城外。甲没喊，只把披风系紧，系到指节发白。风把旗吹倒，没人去扶。 |
| 「为什么！命运！」 | 甲把信叠好，放进乙常坐的那把椅垫下。椅垫陷下去一点，像还有人坐着。 |

## 常见错误

- **哭喊复读**。
- **作者替读者感动**。
- **死亡无铺垫**（除非类型刻意）。
- **立刻翻篇无余波**。

## 与 AI 出题的关系

题目给送别、战死、永诀等。评改看：克制、细节、余波、是否狗血。

## 延伸练习建议

- 80 字告别，禁止「哭、泪、悲伤」。
- 用空椅子/空碗写余波 40 字。
