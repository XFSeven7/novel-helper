# 视角切换

## 本节目标

- **切换有信号**：空行、章隔、时间/地点提示、标题「某某视角」。
- **人称与限知一致**：换头后不知前者未见的秘密（除非设定允许）。
- 切换服务剧情，不为换而换。
- 全知/限知不混穿帮。

## 核心概念

POV 是**摄像机**。网文常见：单主角限知为主，关键章切反派/队友一头。切换代价是读者重新代入，故要有**回报**（信息、爽点、悬念）。

信号要明显：读者不应疑惑「这句谁在想」。切到反派常给「更坏的事正在发生」。

## 怎么做

1. **全书先定 POV 规则**（单主角/双主角/群像）。
2. **切换点选在章首或空行后**。
3. **新 POV 第一句接地**：动作或对话，少心理综述。
4. **检查知识边界**：新 POV 不应知不该知的。
5. **控制频率**：短章忌多头乱跳。

**检查清单**

- [ ] 切换是否有信号？
- [ ] 有无知识穿帮？
- [ ] 切换是否有必要回报？

## 正反例

| 差 | 好 |
| --- | --- |
| 他想。与此同时乙也想……同段乱跳。 | ——乙——城门关闭前，乙已在校场。他不知道甲今夜要逃，他只知道火油不够。 |
| 全知：甲心想秘密，乙段也写甲秘密。 | 甲攥紧信。乙段只写乙看见甲指节发白，看不见信上字。 |
| 切换无标记。 | 【第三章 乙】雨还没停。乙抹刀，刀上是别人的血，不是甲的。 |

## 常见错误

- **同段双 POV**。
- **切换太频**：读者无法代入。
- **反派 POV 变说明书**。
- **人称混乱**：「我」变「他」无规则。

## 与 AI 出题的关系

题目要求写切换段或判断穿帮稿。评改看：信号、限知、必要性。

## 延伸练习建议

- 同事件写甲 POV 80 字、乙 POV 80 字，信息互补不重复。
- 标出一处穿帮并改正。
