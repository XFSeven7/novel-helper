# 演说宣告

## 本节目标

- 写**公开场合**的演说：煽动、立威、宣战、动员，有气势可传播。
- **一句一义**，少从句套从句，适合朗读与扫读。
- 写出**听众反应**（静、哗、跪、骂），不只主角独白。
- 气势来自具体承诺/威胁，不是空喊「崛起」。

## 核心概念

演说在网文里是**情绪放大器**：族长宣布、将军出征、反派宣言。读者很少真听完全文，他们会抓**金句+节奏+人群反应**。

结构常是：**现状痛 → 敌人/不公 → 我方优势 → 具体号召 → 收束口号**。中间要有可验证的细节（「三日之内」「城南三处」），否则像传销。

## 怎么做

1. **定演说目的**：动员打仗？甩锅？洗白？
2. **写 1 句可被截图的金句**，围绕它铺垫。
3. **短句排比**，关键处单独成段。
4. **插 2–3 笔听众**：谁哭、谁骂、谁沉默。
5. **避免网络烂梗**堆砌，除非人物设定就是玩梗。

**检查清单**

- [ ] 删掉能否损失核心信息？（不能说明有料）
- [ ] 是否有具体条件/时间/对象？
- [ ] 听众是否存在？

## 正反例

| 差 | 好 |
| --- | --- |
| 「我们要崛起！我们要胜利！」反复。 | 「粮在城西三仓，刀在你们腰间。明日卯时，开南门——」甲停住，「不开门的，我亲自去敲。」 |
| 他发表了一篇很长的演讲，很感人。 | 台下有人咳了一声，很快压住。甲举起旧旗：「旗还在，人就还在。」风把旗面吹得啪啪响。 |
| 众人听了非常激动。 | 前排老头先跪下去，膝盖撞在石阶上。后面的人还没反应过来，甲已经转身走了。 |

## 常见错误

- **只有口号无利益**：读者不知道跟你有何好处。
- **书面语演讲**：「诸位同仁」「鄙人」滥用除非时代需要。
- **无人群反馈**：像自言自语。
- **过长**：网文演说宜控制在读者耐心内，高潮前置。

## 与 AI 出题的关系

AI 常出：战前动员、宗主传位、反派宣言等。评改看：气势、具体性、听众、句式节奏。

## 延伸练习建议

- 用 150 字写完演说，其中 1 句不超过 8 字。
- 同内容写「煽动版」与「威胁版」各一。
