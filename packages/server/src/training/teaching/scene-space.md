# 室内空间

## 本节目标

- 让读者**看见**房间、车厢、密室、废墟的布局：门在哪、谁离谁几步。
- 写清**人物与空间关系**（堵门、靠窗、缩角落、居高临下）。
- 用 2–3 个**可感细节**定调（霉味、窄、回声、光线从哪来）。
- 空间服务戏剧：逼仄增压迫，空旷增荒凉。

## 核心概念

室内戏本质是**距离与出口**：谁挡着门、谁背靠悬崖（窗）、桌上刀离谁更近。网文打斗、谈判、暧昧，都靠空间站位说话。

先画简图（心理即可）：入口、窗、桌、床。再选读者最该看见的两样东西——**光路**和**障碍**。车厢=窄+晃；密室=无窗+回声；废墟=塌角+风灌入。

## 怎么做

1. **一句总览**：多大多高、一眼看见什么（「一间不足十步的厢房」）。
2. **定人物站位**：谁坐谁站，与门/窗/武器的距离。
3. **写 1 个触觉/嗅觉锚点**：潮、霉、机油、香水过头。
4. **让空间参与动作**：转身撞桌、退半步踩空、声音在头顶炸开。
5. **避免家具清单**：不是「有桌有椅有床」，而是「桌角磕青小腿」。

**检查清单**

- [ ] 读者能否画出简易平面图？
- [ ] 人物移动时空间逻辑是否通？
- [ ] 是否有无关陈设堆砌？

## 正反例

| 差 | 好 |
| --- | --- |
| 房间里有很多家具，很乱。 | 衣堆顶到桌沿，甲侧身才挤进里间；窗外霓虹扫过，光在墙上走一圈又灭。 |
| 车厢里他们坐着。 | 乙贴门坐，车晃一下，肩撞铁皮；甲占着过道边，膝顶到对面座位，退无可退。 |
| 密室很大。 | 手电扫过去，光柱够不着顶；脚步带回声，第二声才让人确认——身后还有一段走廊。 |

## 常见错误

- **空间矛盾**：上文说无窗，下文风吹窗帘。
- **只有清单无关系**：罗列摆设，人物像飘在空中。
- **过大或过平**：「大厅宏伟」却没有声光层次。
- **忽略声音**：密室/车厢不写回声与摩擦声。

## 与 AI 出题的关系

题目常给：密室对峙、车厢谈判、废墟过夜等，要求布局清晰。评改看：空间是否可想象、人物站位、细节可感、是否服务冲突。

## 延伸练习建议

- 画简图后只用文字描述，请他人复述站位是否一致。
- 把「房间很乱」扩成 80 字，只写 3 样具体物件及其位置。
