# 开篇入戏

## 本节目标

- **300 字内**让读者知道：谁、在哪、有什么事不对劲/有趣。
- **场面进场**，少设定堆砌、族谱、世界观百科。
- 尽快建立**冲突或悬念**：异常、羞辱、危机、诱惑。
- 开篇句要有**钩子**（动作、对话、反常细节）。

## 核心概念

网文开篇 = 抖音前 3 秒。读者滑动之间决定是否追读。有效开篇：**人物+目标/麻烦+语气**。

忌「清晨的阳光」式散文慢热；忌「在这个世界里有九重天」说明。用**异常**拉人：婚礼现场来了棺材、主角醒来欠百万、一句侮辱性对话。

## 怎么做

1. **第一句动或疑**：动作、对话、反常物。
2. **100 字内给人物一个处境**（压、辱、急、喜）。
3. **设定拆进冲突**（通过对话、规则惩罚体现）。
4. **章末小钩子**（即使开篇段也要有向前拽的力）。
5. **删风景与背景史**，除非风景就是刀。

**检查清单**

- [ ] 前 300 字是否有冲突/悬念？
- [ ] 设定说明是否可后移？
- [ ] 能否换成任意角色而不违和？

## 正反例

| 差 | 好 |
| --- | --- |
| 这是一个修仙世界，分为九重天……（接设定） | 「退婚？」甲把信捏皱，「谁写的？」门外笑声停了，乙的声音飘进来：「我写的。」 |
| 清晨，阳光洒满山谷，很美。 | 血先于脚步声进帐。甲睁眼，刀在枕边，刃口缺了——缺的那块，在来人喉间。 |
| 主角出生在一个普通农家…… | 账房把算盘一推：「你家欠的，连你儿子算上，还差这条命。」孩还在襁褓里，没哭。 |

## 常见错误

- **设定开场**。
- **无人物无事件**的风景/感慨。
- **主角太被动**：看天下雨三页。
- **钩子虚假**：吓人却无后文。

## 与 AI 出题的关系

题目常要求 150–400 字开篇，指定类型（玄幻、都市、悬疑）。评改看：入戏速度、冲突、设定密度、钩子。

## 延伸练习建议

- 写 3 个不同第一句，选最狠的扩到 200 字。
- 把设定开篇改成「冲突中露设定」。
