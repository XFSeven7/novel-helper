# 打脸爽点

## 本节目标

- 写出**压抑—释放**曲线：铺垫够，释放干脆。
- **当众反转**有见证人（围观、敌人、曾经嘲笑者）。
- 释放点用**动作+结果**，少「众人震惊」空话。
- 爽而不尬：逻辑通，反派别太弱智。

## 核心概念

打脸是网文**情绪期货**：先让读者憋屈（被退婚、被嘲、被踩），再一次性兑现。铺垫越长，释放要越短越狠。

结构：**羞辱具体 → 主角隐忍/布局 → 证据/实力落地 → 对方反应（脸变、腿软、话碎）**。忌作者替读者爽：「太爽了」。

## 怎么做

1. **铺垫写具体辱**（一句话、一个物、一个规则）。
2. **释放前停半拍**（安静、问一句）。
3. **用结果说话**：榜名、战力、合同、圣旨。
4. **写 1–2 个见证者反应**，不说「震惊」。
5. **收束快**，不追打落水狗超过读者耐心。

**检查清单**

- [ ] 是否有足够铺垫？
- [ ] 释放是否干脆？
- [ ] 是否空洞「震惊」？

## 正反例

| 差 | 好 |
| --- | --- |
| 众人震惊，太爽了。 | 榜文钉上墙，「甲」在第一行。乙念到一半，声音卡在被自己的唾沫里。甲没看他，把披风系紧，走了。 |
| 他打脸成功，反派很惨。 | 「方才谁说要废他修为？」甲问。堂上静。老头颤巍巍站起：「老朽……眼拙。」甲把令牌放回桌，令牌角砸进木里。 |
| 反派立刻跪地求饶长篇。 | 乙膝盖撞地，先于话。甲俯身，只说一句：「婚书，撕哪边？」 |

## 常见错误

- **无铺垫就爽**：读者无感。
- **释放拖**：解释、嘲讽循环。
- **反派降智**：为爽而爽。
- **作者解说爽感**。

## 与 AI 出题的关系

题目常给：宴会、擂台、商会打脸情境。评改看：铺垫、释放、见证、逻辑。

## 延伸练习建议

- 先写 60 字辱，再写 40 字反转，禁止「震惊」。
- 用物件（榜、印、剑）完成释放，不用形容词。
