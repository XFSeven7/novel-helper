## 本节目标

- 能用动作、生理反应、环境反馈表达情绪，避免「很害怕」「非常开心」等空标签。
- 每段至少落地 2–3 个可感知的感官锚点（光、声、触感、气味）。
- 减少「凌厉」「巨大」「无比」等无法验证的形容词。

## 核心概念

**展示（Show）而非告知（Tell）**：读者要「看见、听见、感觉到」，而不是被作者告知情绪等级。网文画面感不是文艺散文，而是**可拍、可想象的细节**，服务于追读与代入。

具象化 = 动词 + 可被检验的细节。情绪是结果，动作与身体是原因。

## 怎么做

1. 写出情绪词后，**划掉**，改写成动作或生理反应。
2. 为场景选 **2 个感官通道**（例如：冷+湿、光+声）。
3. 形容词后加「凭什么」：「巨大的门」→「门楣擦过他头顶」。
4. 对话与动作交叉，避免连续三句纯描写。

**检查清单**

- [ ] 是否删掉了「很××」情绪标签？
- [ ] 是否有动词驱动？
- [ ] 读者能否在脑中形成画面？

## 正反例

| 差（告知） | 好（展示） |
| --- | --- |
| 他非常害怕。 | 他指甲抠进掌心，牙关止不住地磕碰。 |
| 她非常开心。 | 她蹦了一下，笑声撞在走廊墙上又弹回来。 |
| 房间很乱。 | 衣堆顶到桌角，空罐头在脚边滚了半圈。 |

## 常见错误

- **堆砌形容词**：「绝美」「恐怖」「震撼」连用，没有画面。
- **只有视觉**：忽略声、触、味，场景发飘。
- **描写与 POV 脱节**：路人视角却写主角内心微观细节。
- **描写阻断剧情**：大段风景，人物三天没动。

## 与 AI 出题的关系

题目常给「毛病稿」或情绪标签句，要求改写成展示体；或指定场景写 120–300 字画面。严师看感官锚点数量、是否贴情绪、有无空洞评价词。

## 延伸练习建议

- 用 50 字只写「雨夜等人」，禁止出现「孤独」「紧张」。
- 把一段对话前后的情绪，全部改成动作与环境反馈。
