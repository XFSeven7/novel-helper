# 争吵对峙

## 本节目标

- 写**冲突层层升级**的争吵，不是同一情绪强度复读。
- 台词**带刀**：短、准、戳对方软肋，少口号式「我不服」。
- 情绪有**因果**：每句翻脸都有前文铺垫或当场刺激。
- 用动作、停顿、破坏物体现失控，少写「他很愤怒」。

## 核心概念

争吵戏是**信息+情绪双释放**。网文争吵要快：先压后爆，每 2–3 轮抬一档——从讽刺到揭短到决裂。读者要感到「挡不住了」。

话在前、单句成段。越吵句子越短。避免两人都喊大道理；至少一人要**占理或占势**，否则像泼妇骂街。

## 怎么做

1. **定争吵目标**：要分手？要承认？要逼对方签字？
2. **列双方软肋**：各 1 条，第三回合再揭。
3. **升级阶梯**：嘲讽 → 质疑人品 → 翻旧账 → 不可挽回。
4. **插入物理动作**：摔杯、拽门、逼近一步。
5. **留一句未说完的话**或突然安静，比吼完更有力。

**检查清单**

- [ ] 是否越吵越狠，而不是原地跺脚？
- [ ] 有无说明式「他很愤怒」？
- [ ] 台词能否演出来（口型不尴尬）？

## 正反例

| 差 | 好 |
| --- | --- |
| 「我不服！」「你凭什么！」来回三遍。 | 「凭你三年前跪下的那张纸。」甲把复印件甩桌上。乙嘴唇动了一下，没出声。 |
| 甲非常生气地说了很多话。 | 「行。」甲点头，笑了一下，「那你现在滚。」乙才意识到门钥匙在甲兜里。 |
| 他们吵得很激烈。 | 乙嗓音劈了：「你骗我——」甲打断：「骗？你早知道。」屋里只剩钟表。 |

## 常见错误

- **情绪标签代替台词**：「愤怒地说」「撕心裂肺」。
- **对称复读**：你一句我一句，信息量零增长。
- **全员圣人**：吵半天没人说人话，像辩论赛。
- **升级过快**：第一句就离婚/去死，后面无路可走。

## 与 AI 出题的关系

题目常给：情侣、师徒、合伙人翻脸等，要求升级+带刀。评改看：层次、因果、说明体、节奏。

## 延伸练习建议

- 写 12 句对话，第 1 句客气，第 12 句不可挽回。
- 删掉所有情绪形容词，只靠台词与动作。
