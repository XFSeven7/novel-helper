# 误导反转

## 本节目标

- **先错后真**：读者先走向错误结论，再合理翻转。
- 误导要**合理**，不能骗读者（作弊式隐藏 POV 关键信息）。
- 反转有**伏**：回看能发现线索。
- 翻转后改变行动方向。

## 核心概念

误导是悬疑/爽文的**双层蛋糕**：表层凶手、表层宝物、表层盟友。真相反转时，旧细节换颜色。

网文可用：**视角限知**正当误导；不可用：叙述者撒谎无信号。翻转宜快，解释宜短。

## 怎么做

1. **设计表层故事**（读者会信什么）。
2. **埋 2 条真线索**混在假线索里。
3. **翻转用证据**，不用「其实我是」一句。
4. **写角色反应**（被骗者的愣、怒、笑）。
5. **翻转后立刻推进**，不停在解释。

**检查清单**

- [ ] 误导是否公平？
- [ ] 反转是否有伏？
- [ ] 是否解释过长？

## 正反例

| 差 | 好 |
| --- | --- |
| 其实凶手不是他，是我，没想到吧。 | 甲指乙：「刀是他的。」乙袖口确实有血。直到伙计抖出当票——当夜乙在当铺，血是羊血，有人借他衣。甲看向柜台后：「你说呢，掌柜？」 |
| 读者完全无法猜到的反转。 | 全程写丙可怜，丙献祭救人。最后一页，丙接过神器，笑：「谢谢你们演完。」——前文丙三次「无意」指路敌人。 |
| 反转后作者解释五百字。 | 丁摘下面纱。甲没说话，只把桌上那枚钮扣翻过来——内侧刻丁的名。丁伸手要夺，甲先一步按住。 |

## 常见错误

- **机械反转**无伏。
- **欺骗读者**（叙述作弊）。
- **反转为了反转**不影响剧情。
- **假线索过多**读者疲。

## 与 AI 出题的关系

题目要求写误导段+反转段。评改看：合理性、伏笔、节奏、是否作弊。

## 延伸练习建议

- 写 80 字误导 + 40 字反转。
- 标出 2 处伏笔句。
