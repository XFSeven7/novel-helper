# 回忆插叙

## 本节目标

- 用**触发物**自然切入回忆（气味、旧物、台词半句）。
- 闪回**短小**、与当下勾连，回来要有落点。
- 回忆承担功能：解释动机、对比今昔、埋反转。
- 避免「那年春天」式无触发硬切。

## 核心概念

插叙是**现在的注释**，不是另开一本书。网文闪回宜控制在读者耐心内，且回来时用当下动作「咔」一声拉回（睁眼、雨停、人喊名）。

结构：**触发 → 碎片画面（动词+细节）→ 回到现在 + 情绪变化**。碎片里少背景概述，多一个镜头。

## 怎么做

1. **先写当下 1 句**，再写触发。
2. **闪回只给 1 个场景切片**，不从头讲到尾。
3. **时态/排版信号**：空行、斜体、或「——」区隔（按全书惯例）。
4. **回来写身体反应**：手松了、脚步快了。
5. **删闪回里可删的设定**，留情绪与关键物。

**检查清单**

- [ ] 是否有明确触发？
- [ ] 回来是否有落点？
- [ ] 闪回是否过长？

## 正反例

| 差 | 好 |
| --- | --- |
| 他想起多年前的事。（接 500 字回忆） | 铁锈味。甲拇指蹭过刀背——七岁，后院也是这味，父亲的手按着他握柄。雨声把回忆截断。院门在响。 |
| 回忆杀开始，详细讲述童年。 | 「茶凉了。」乙说。甲低头，杯沿一圈唇印，不是乙的。他放下，没喝。 |
| 闪回结束后继续剧情，无衔接。 | 甲回神，发现自己已走到门口；手里握着那把从未寄出的信，指节发白。 |

## 常见错误

- **无触发硬切**。
- **闪回=说明书**：补设定无戏。
- **回来无变化**：闪回不影响当下决定。
- **频率过高**：章章闪回。

## 与 AI 出题的关系

题目常给：旧物、故人、战场 PTSD 等触发写插叙。评改看：触发、长度、勾连、落点。

## 延伸练习建议

- 闪回不超过 120 字，回来用 1 句动作。
- 同一触发写「甜回忆」与「怖回忆」各一。
