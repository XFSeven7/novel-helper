# 电话语音

## 本节目标

- 练**只听一侧**的对话：省略、停顿、打断要够。
- 用**信息差**制造张力（读者知道另一方不知道）。
- 声音媒介感：信号差、环境噪、听筒贴耳、免提外放。
- 禁止把电话写成面对面般完整描写双方表情（除非免提在场）。

## 核心概念

电话/语音戏强迫你**只靠台词与间隙**讲故事。网文里报信、威胁、撒谎、分手都适合。一侧可见、一侧不可见 = 天然悬念。

技巧：**断句、重复、说一半挂、误听**。「你说什么？——我说……」比写满更有戏。环境声提示地点：车流、风声、另一头有人催。

## 怎么做

1. **只写 POV 一侧台词+反应**（除非双声道设定）。
2. **每 2–3 句插一次停顿或杂音**。
3. **用「……」「喂？」「信号」推动节奏**。
4. **关键信息晚半拍透露**。
5. **结束方式要有力**：挂断、忙音、对方先挂。

**检查清单**

- [ ] 是否像电话而不是面对面？
- [ ] 是否有信息差或误解？
- [ ] 是否滥用「对方说」描写不可见侧表情？

## 正反例

| 差 | 好 |
| --- | --- |
| 电话里对方告诉他一切，他很震惊。 | 「人到了。」那头说。甲握紧手机：「几个？」忙音。三秒后短信亮：一个数字。 |
| 对方在电话里把计划详细说了一遍。 | 「你别管——」「我管不管，」甲压低声音，「你那边有风声。」电话那头静了两秒，换了个人接：「谁让你打的？」 |
| 他们聊了很久电话。 | 甲耳朵发烫，把手机换边：「……行，就今晚。」窗外警笛过去，他没听见那头最后半句。 |

## 常见错误

- **写不可见侧动作**：「对方皱起眉头」—— POV 看不见。
- **信息一次倒完**：无停顿无反复。
- **无媒介感**：像微信长文。
- **挂断无后果**：下一场像没打过。

## 与 AI 出题的关系

题目常给：报丧、勒索、谎言拆穿、远程指挥等，只写一侧。评改看：省略、停顿、信息差、媒介真实感。

## 延伸练习建议

- 80 字电话戏，禁止出现「对方说」。
- 设计一次「听错关键词」导致误会。
