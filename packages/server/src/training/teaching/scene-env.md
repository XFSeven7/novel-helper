# 环境写景

## 本节目标

- 用**具象五感**（光、声、触、味、嗅）写出可想象的场景，而不是空泛抒情。
- 让景物**服务当下情绪与剧情**，景不为景、不为凑字数。
- 每段至少落地 **2–3 个感官锚点**，读者能「站进」场景里。
- 删掉「很美」「令人心碎」等无法检验的评价句。

## 核心概念

环境写景不是散文练笔，是**情绪与信息的载体**。网文读者扫读快，环境句要短、要准、要有功能：交代时间地点、暗示危险、衬托人物状态、控制节奏（紧张用短句碎声，舒缓才可略铺）。

**景随情动**：同一间屋子，主角得意时看见的是敞亮窗光；心虚时先听见自己的呼吸和钟摆。先定「这段戏人物什么状态」，再选 2 个感官去写，比先写景再贴情绪高效得多。

## 怎么做

1. **先定情绪/功能**：这段环境要告诉读者什么？（危险临近 / 安全假象 / 物是人非）
2. **选 2 个感官通道**：例如雨夜 = 湿冷触感 + 远处车声；忌五感全上。
3. **动词优先**：风「灌」进门缝、灯「晃」了一下，少用「凌厉」「巨大」。
4. **划掉情绪标签**：「他很孤独」→ 空荡楼道里只有自己的脚步声。
5. **控制长度**：练习 70–450 字；连载里环境块不宜连续超过 3–5 行。

**检查清单**

- [ ] 是否删掉了空泛抒情与「很××」？
- [ ] 是否有 2–3 个可感细节？
- [ ] 删掉环境后，剧情/情绪是否塌掉？（若不会，说明景多余）

## 正反例

| 差 | 好 |
| --- | --- |
| 夜色很美，他心情复杂。 | 路灯坏了一盏，光在积水里碎成锯齿；他把领子竖起来，还是挡不住后颈的凉。 |
| 房间里充满了恐怖的气氛。 | 衣柜门缝卡着半张纸条，风一过，纸边在地板上蹭出细响。 |
| 春天来了，万物复苏。 | 巷口炸油条的气味先于人声涌过来，甲把最后一口包子咽下去，才踏进衙门。 |

## 常见错误

- **为写景而写景**：大段风景，人物三天没动。
- **只有视觉**：没有声、触，场景发飘。
- **陈词滥调**：「月光如水」「花香扑鼻」不加改造直接用。
- **与 POV 脱节**：路人视角却写主角微观生理细节。

## 与 AI 出题的关系

AI 常出：指定情境（雨夜巷口、废弃厂房、清晨集市）写 120–300 字；或给「毛病稿」要求删抒情改具象。评改看：感官锚点数量、是否贴情绪、有无空洞形容词、景物是否推动读下去。

## 延伸练习建议

- 用 80 字写「等人」，禁止出现「紧张」「孤独」等词。
- 把一段对话前后的环境，各用 2 句重写，分别对应说话人前后心态变化。
