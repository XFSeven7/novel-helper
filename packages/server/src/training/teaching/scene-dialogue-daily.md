# 日常对话

## 本节目标

- 写出**自然、有人味**的日常对白，像真人说话而不是论文。
- 每句对话至少承担一项功能：推事、立人设、藏信息、留钩子。
- 会用**潜台词**——嘴上说的和心里想的不完全一样。
- 删掉寒暄灌水（「你好」「吃了吗」连篇除非有戏）。

## 核心概念

日常对话是网文的**呼吸段**：给读者缓一口气，同时偷偷塞信息。好的日常 = 口语节奏 + 人物习惯 + 一点摩擦。甲乙说话方式要可区分：一个爱打断，一个爱绕弯。

网文排版：话在前、关键句单独成段、快打可零标签。日常戏也要**有目的**——问饭是假，试探家底是真。

## 怎么做

1. **写前先问**：这段不说，剧情会不会断？
2. **给每人一个说话习惯**：短句/长句、爱反问、爱省略。
3. **埋半句信息**：「那件事……算了。」比解释更有味。
4. **用动作打断对话**：夹菜、看手机、避眼神。
5. **3–5 轮后点一次谁在说**：快打时靠习惯区分。

**检查清单**

- [ ] 能否删掉一半句子而不影响理解？（能删就删）
- [ ] 是否有信息差或微妙冲突？
- [ ] 两人说话是否像同一个人？

## 正反例

| 差 | 好 |
| --- | --- |
| 「你好。」「你好。」「天气不错。」 | 「你来干嘛？」乙把茶壶按在杯口，没倒。「路过。」甲目光往里间飘了一下。 |
| 甲说：「我觉得我们应该谈谈那件事。」 | 「合同我带了。」甲拍桌。乙没接：「不急，先喝茶。」 |
| 两人聊了很久，很开心。 | 乙笑了三次，一次都没看甲眼睛；第三次笑完，把糖碟推远了。 |

## 常见错误

- **说明式对话**：用嘴讲设定、背景、世界观。
- **人人播音腔**：书面语、完整长句、无口语词。
- **无功能寒暄**占半章。
- **标签复读**：「他冷冷地说道」每句都来。

## 与 AI 出题的关系

AI 常出：邻里、同事、家人日常场景，要求自然+潜台词。评改看：人味、信息量、删水、排版是否利扫读。

## 延伸练习建议

- 用 8 句对话完成「借钱」，双方都不直说「借」字。
- 把一段说明式设定对话改成「问一句答半句」。
