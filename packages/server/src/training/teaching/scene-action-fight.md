# 打斗交锋

## 本节目标

- 用**短句、动词**写近身/法术/兵器交锋，节奏快于叙述。
- 保持**空间感**：谁在哪、距离变化、障碍利用。
- 写出**力量代价**：喘气、受伤、兵器损、灵气空。
- 避免「无敌感」与招式名堆砌无画面。

## 核心概念

网文打斗读者要**看清怎么赢/怎么输**。一句一动：挡、卸、进、退。长句解释招式原理会拖死节奏。

结构：**接触 → 交换 → 转折 → 结果**。转折靠环境（滑倒、灯灭、第三人）或先前伏笔（暗器、旧伤），不靠突然升级。

## 怎么做

1. **定胜负与代价**（赢也要付什么）。
2. **动词表**：砍、崩、贯、缠、踏、拧——少用「攻击」「释放」。
3. **每 2–3 句写一次位置**：贴脸、拉开、背抵墙。
4. **写 1 个感官**：金属味、血温、耳鸣。
5. **控制专有名词**：术名一次即可，重复要有意义。

**检查清单**

- [ ] 能否在脑中跟完动作？
- [ ] 是否有空泛「大战三百回合」？
- [ ] 打完是否有代价？

## 正反例

| 差 | 好 |
| --- | --- |
| 两人大战三百回合，天昏地暗。 | 乙刀走偏锋，甲格挡，虎口发麻；第三刀贴耳过去，削断一缕发。甲退半步，背撞桌沿。 |
| 他使出了绝招，非常厉害。 | 甲气贯掌心，乙却矮身从烟里穿出——烟是刚才砸碎的香炉，呛的是甲。 |
| 战斗很激烈，难分胜负。 | 剑尖点地，拖出细响。乙喘了一口，膝弯了一下；甲没追，因为右肩已经抬不起来。 |

## 常见错误

- **招式说明书**：只报名字无动作。
- **无空间**：两人在虚空中互殴。
- **无代价**：打完像没事。
- **节奏拖沓**：一句动作接三句心理。

## 与 AI 出题的关系

题目常给：巷战、擂台、法术对轰等。评改看：动词、空间、代价、节奏。

## 延伸练习建议

- 80 字写完一场交锋，禁止「强大」「恐怖」形容词。
- 加入环境一物改变胜负。
