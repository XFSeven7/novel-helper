## 本节目标

- 能用「起承转爽/钩」组织单章或片段，避免平铺直叙。
- 会在段末或章末留下悬念、危机或反转之一。
- 知道大高潮后需要 2–3 章缓冲，避免读者疲劳。

## 核心概念

追读 = 读者愿意点下一章。网文连载的骨架不是文学课的「起承转合」，而是**压力升级 → 回报/反转 → 新悬念**。

- **起**：承接上章 + 本章小目标（读者知道要等什么）。
- **承**：阻力加大、代价提高。
- **转**：意外、底牌、信息反转。
- **爽/钩**：小回报 + 未解问题（章末最常留钩）。

章末平淡 = 帮读者按退出。

## 怎么做

1. 写章前先写一句「本章读者要爽到什么 / 要担心什么」。
2. 每 800–1200 字自问：有没有新信息或新压力？
3. 章末最后 1–3 段，强制落一个钩子（悬念/危机/反转）。
4. 大高潮章之后，下一章降半档强度，再爬升。

**检查清单**

- [ ] 本章是否有明确推进？
- [ ] 是否有情绪回报或爽点？
- [ ] 结尾是否让人想问「然后呢」？

## 正反例

| 差（拖沓收尾） | 好（带钩） |
| --- | --- |
| 他回到房间，躺在床上，慢慢睡着了。 | 他推开房门。 桌上放着一只空信封。 封口是他自己的指印——可他从没写过这封信。 |
| 战斗结束了，大家都很高兴。 | 甲收刀。 乙在笑。 笑到第三声，甲才发现乙的袖子底下在滴血——不是乙的血。 |

## 常见错误

- **只有承没有转**：压抑三章仍无释放，读者流失。
- **钩子等于故弄玄虚**：没有铺垫的「神秘人」。
- **章内重复同一冲突**：吵架吵三遍，信息不升级。
- **高潮后立刻更大高潮**：节奏疲劳。

## 与 AI 出题的关系

题目常要求写「章骨架提纲」「章末钩子」「起承转爽四段摘要」。严师看结构是否推进、钩子是否具体、是否拖沓。

## 延伸练习建议

- 给任意开篇 300 字，只写章末 150 字钩子，类型自选（悬念/危机/反转）。
- 拆榜单章：标出起承转爽各落在哪一段。
