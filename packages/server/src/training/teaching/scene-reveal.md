# 信息揭晓

## 本节目标

- **抖包袱**节奏：证据一件件落地，不是作者一次性说明。
- 揭晓让读者「原来如此」而非「早猜到了」或「啥？」。
- 证据**可验证**（信、伤、时间线、第三人）。
- 揭晓后改变局面：谁被抓、谁逃、谁改目标。

## 核心概念

揭晓是**信息差结算**。前文埋线索，揭晓时至少亮 2 条，读者拼得上。网文忌「其实我是你爹」无铺垫。

结构：**怀疑 → 试探 → 铁证 → 反应**。铁证宜具体：账本页、刀上纹、阵法缺一角。

## 怎么做

1. **列读者已知线索**（揭晓时呼应至少 2 条）。
2. **用对话或物证**，少旁白总结。
3. **写被揭方的破防动作**，不只「不可能」。
4. **控制节奏**：一句比一句狠。
5. **揭晓后接新麻烦**（钩子）。

**检查清单**

- [ ] 是否有铺垫可回溯？
- [ ] 是否作者全知_dump？
- [ ] 揭晓后局面是否变化？

## 正反例

| 差 | 好 |
| --- | --- |
| 原来一切都是阴谋，作者是这么安排的…… | 甲把第三页账摊开：「上月十五，你在城西买炭。」乙：「那又如何？」甲：「城南火也是上月十五。炭灰，在你袖口。」 |
| 真相大白，大家都很震惊。 | 玉佩缺角对上了。乙伸手要接，甲先一步扣住乙腕：「缺角是你娘留下的。偷玉的人，右手有烫伤。」乙右手缩回袖里。 |
| 他揭露了所有真相。（无证据） | 「你不是说没见过他？」甲抬下巴。门开，瘸腿伙计进来，手里是当夜的当票。乙看向伙计，再看甲，没说话。 |

## 常见错误

- **无证据揭晓**。
- **读者早猜完**还拖章。
- **揭晓=回忆录**长篇解释。
- **无后果**。

## 与 AI 出题的关系

题目给线索与揭晓场景。评改看：节奏、证据、铺垫呼应、局面变化。

## 延伸练习建议

- 先列 3 条伏笔，再写 100 字揭晓。
- 写「读者猜对一半」的揭晓（真相比猜的更狠一点）。
