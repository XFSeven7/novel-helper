# 追逐逃亡

## 本节目标

- 写出**追与逃的节奏递进**：障碍、喘息、距离拉近或拉远。
- **地形参与**：楼梯、人群、死巷、屋顶、车流。
- 短句为主，读者感到「来不及喘」。
- 逃亡方要有**明确目标**（门、人、车），不是乱跑。

## 核心概念

追逐戏 = **时间压力 + 路线选择**。每一障碍都要改变距离：绊倒、抄近道、电梯门合拢、马匹失蹄。

网文忌「跑了很久」；用**地标切换**：街口 → 巷子 → 河堤，读者知进度。声音层次：脚步、喊声、犬吠、轮胎。

## 怎么做

1. **定逃者要去哪、追者要抓什么**。
2. **列 3 个障碍**，一个比一个紧。
3. **写呼吸与身体**：肺疼、侧 stitch、回头误绊。
4. **用声音提示距离**：脚步远/近、哨音。
5. **收束要有结果**：抓住、甩开、或被迫转向。

**检查清单**

- [ ] 节奏是否递进？
- [ ] 地形是否清楚？
- [ ] 是否有「跑很久」空叙述？

## 正反例

| 差 | 好 |
| --- | --- |
| 他跑啊跑，追兵紧追不舍。 | 甲撞翻菜摊，葱叶糊鞋上滑了一下；身后铁器刮过石阶，近了一臂。他扑进窄巷，肩擦墙皮掉灰。 |
| 追逐很紧张刺激。 | 乙跳过断墙，落地膝弯；马嘶在巷口——不是他的马。他改道翻窗，窗框木刺划袖，没停。 |
| 终于甩掉了追兵。 | 甲蜷在桥洞下，数到第七批脚步过去，才松口咬着的布条。布条上都是血沫。 |

## 常见错误

- **无路线**：不知道往哪跑。
- **障碍无效**：绊了还能匀速跑。
- **追兵消失**：无交代甩开。
- **只有跑无选择**：无转弯、无牺牲（丢包、推人挡路要慎用伦理）。

## 与 AI 出题的关系

题目常给：城追、林追、车追等。评改看：递进、地形、节奏、目标是否清晰。

## 延伸练习建议

- 用 100 字写三段距离：远、中、贴脸。
- 加入一个「假出口」再真出口。
