# 群戏场面

## 本节目标

- **主次分明**：主角线清晰，路人不过抢戏。
- **声音层次**：喧哗、私语、突然安静、一人插话。
- 多人各怀鬼胎时，用**小动作**区分立场。
- 控制群戏长度，忌人人有名有姓。

## 核心概念

群戏是**多线程对话+空间**。网文常用：宗族大会、战场集结、集市、拍卖。读者只需记住 2–3 个关键配角，其余用「席位」「角门」「穿灰衣的」指代。

技巧：**先全景一句，再特写一人一句**，交替。爆发点用「全场静」再落一句狠话。

## 怎么做

1. **定本场主角要拿到什么**（信息、地位、资源）。
2. **标 3 个势力**，各 1 个代表动作。
3. **用声音写层次**：吵→某声压过→窃语再起。
4. **关键台词单独成段**。
5. **删无名路人内心**。

**检查清单**

- [ ] 主角目标是否清楚？
- [ ] 是否人脸混乱？
- [ ] 是否有层次变化？

## 正反例

| 差 | 好 |
| --- | --- |
| 很多人说话，很乱。 | 堂上七嘴八舌。甲敲了一下扶手，木声不大，后两排却先静了。乙在角落笑，没起身。 |
| 群像每个都介绍一遍。 | 前排三人拱手，后排只闻酒气。甲目光扫过——第三桌袖口绣蛇的，手指在杯沿敲，敲法和昨日刺客一样。 |
| 场面很宏大震撼。 | 号角没停，人却往两侧退，像水让石。甲牵着马从中间走，马鼻喷白雾，蹄铁踩在血冰上，咔咔响。 |

## 常见错误

- **人人对白**无主次。
- **只有吵无静**。
- **介绍性群像**。
- **空间不清**谁站哪。

## 与 AI 出题的关系

题目给宗族、军阵、集市等群戏。评改看：主次、层次、目标、混乱度。

## 延伸练习建议

- 100 字群戏，只准 2 人有名。
- 用「静」写权力转移一次。
