# 氛围烘托

## 本节目标

- 用环境、细节、节奏**暗示**情绪，不直写「害怕/高兴/诡异」。
- 能写出**诡异、喜庆、肃杀、暧昧**等类型气氛，读者一进段就有体感。
- 减少告知体（「气氛很压抑」），改成可检验的画面与声音。
- 氛围与**即将发生的事**一致，不搞无关恐怖。

## 核心概念

氛围 = 读者对「接下来会怎样」的**潜意识预期**。网文靠类型惯例：红灯笼、鞭炮、笑声堆叠 → 喜庆；钟停、虫无声、灯闪 → 不安。你不说「诡异」，读者也能汗毛竖起。

关键是**选择性细节**：喜庆场面写人声、热气、红色；肃杀场面写金属声、空旷、冷色。同一物件不同写法，气氛就反了（婚礼上的白烛 vs 灵堂的白烛）。

## 怎么做

1. **先定气氛词**（只给自己看）：肃杀 / 甜腻 / 虚假热闹……
2. **列 3 个能暗示它的细节**：声音、光、气味、人的小动作。
3. **禁止情绪直说**：全文不出现「恐怖」「温馨」等总结句。
4. **用节奏辅助**：短句碎段 → 紧；长句缓铺 → 沉（别在高潮前缓太久）。
5. **留一点空白**：不说满，让读者脑补（门后是什么，先不写）。

**检查清单**

- [ ] 遮住段首段尾，中段能否猜出气氛？
- [ ] 是否零「很××」气氛标签？
- [ ] 细节是否同一方向，没有又喜庆又恐怖除非刻意反讽？

## 正反例

| 差 | 好 |
| --- | --- |
| 这里的气氛非常诡异。 | 走廊尽头的风铃没人碰，却隔一阵响一声；灯泡接触不良，人脸忽明忽暗。 |
| 婚礼很热闹，大家很开心。 | 唢呐盖过笑闹，桌碗碰在一起叮叮当当；乙敬完酒，袖口还在滴。 |
| 战场气氛肃杀。 | 泥里混着断旗，旗角湿了，贴在杆上不再动；远处鼓声停了，只剩马喷鼻息。 |

## 常见错误

- **标签式氛围**：「空气凝固了」「令人窒息」连用。
- **细节打架**：前面喜庆后面无铺垫突然闹鬼（除非类型就是反转）。
- **堆砌阴森意象**：蝙蝠、黑猫、血月全上，反而卡通。
- **与人物行动脱节**：氛围吓人，人物却在聊家常。

## 与 AI 出题的关系

题目常要求：指定气氛类型（诡异老宅、虚假宴会、战后废墟），不写情绪词，用 100–350 字烘托。评改看：是否到位、有无告知体、细节是否统一、是否服务后续情节。

## 延伸练习建议

- 同一场景各写 60 字，一版喜庆一版肃杀，不许重复物件。
- 给一句「气氛很紧张」毛病稿，改写成 3 个感官细节。
