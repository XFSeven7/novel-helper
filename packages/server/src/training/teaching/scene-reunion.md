# 重逢相认

## 本节目标

- 控制**信息释放节奏**：认人、相认、情绪翻涌分步给。
- 避免**一眼假**（「是你！」「真的是你！」无铺垫）。
- 用**触发物**（声音、伤疤、习惯动作）建立可信度。
- 重逢要有**时间差**：彼此已不是当年那个人。

## 核心概念

重逢戏读者要的是**落差**：记忆里的少年 vs 眼前这个人。网文常用：战乱、修仙闭关、失忆、假死归来。

好重逢 = **试探 → 证据 → 确认 → 情绪失控或强压**。别第一步就抱头痛哭；让证据说话（旧伤、旧话、只有两人知道的丑事）。

## 怎么做

1. **先写「不敢认」或「认不出」**。
2. **给 2 个识别点**：一外一内（疤+口头禅）。
3. **情绪晚一步爆发**：先静，后手抖/声劈。
4. **写旁人或环境**：路人问话、雨声、人群隔开。
5. **留半句旧称或旧承诺**，比解释当年更有力。

**检查清单**

- [ ] 相认是否有过程？
- [ ] 是否有「一眼假」台词？
- [ ] 是否写出时间带来的变化？

## 正反例

| 差 | 好 |
| --- | --- |
| 「是你！」「是我！」两人拥抱。 | 甲先看见的是对方左手缺了小指——那年崖上滚落时卡住的。他开口，嗓子发涩：「……还喝茶吗？」 |
| 他们重逢很感人。 | 乙站在三步外，没上前：「你姓什么？」甲愣住，笑不出来：「你教的字，你忘了？」 |
| 分离多年，他们终于见面了。 | 人群挤过，甲只抓住对方袖口一瞬，布料旧了，磨毛了。对方回头，眼神先警惕，后空了一拍。 |

## 常见错误

- **无证据相认**：靠作者说「他认出来了」。
- **情绪一步到位**：无试探直接哭。
- **设定解释大会**：重逢变回忆录。
- **外貌描写代替戏**：半页五官无动作。

## 与 AI 出题的关系

题目常给：战场、街头、宴会上故人。评改看：节奏、证据、真实感、是否一眼假。

## 延伸练习建议

- 相认过程至少 4 步，最后一步才叫出名字。
- 写「认错了人」的虚惊一场，再真认。
