# 章末悬念

## 本节目标

- **断在问题上**：读者想知道「然后呢」。
- **不泄底**：真相、凶手、底牌留到下一章。
- 钩子要**具体**：一声异响、半句话、意外来客、规则触发。
- 与本章内容有关，不是凭空吓一声。

## 核心概念

章末钩子是连载的**留存率核心**。类型惯例：危机升级、反转半揭、新规则出现、人物做不可逆选择。

好钩子 = **信息差**：读者刚比主角多知道一点，或主角刚比读者多知道一点。忌「他感到不妙」无物。

## 怎么做

1. **回顾本章末情绪**：压到最高再断。
2. **选断点类型**：问句、到来、发现、选择未做。
3. **最后一段宜短**，甚至一句。
4. **删解释**：「这意味着……」留到下一章。
5. **检查是否泄底**：若谜底已全说，换断点。

**检查清单**

- [ ] 合上书是否想问「然后呢」？
- [ ] 是否泄底？
- [ ] 是否空洞（「危险逼近」）？

## 正反例

| 差 | 好 |
| --- | --- |
| 他感到一种不祥的预感。 | 门自己开了一条缝。缝里没有风，伸出一只手——指甲涂的色，和新娘一样。 |
| 下一章将会有大事发生。 | 「签了吧。」乙推过纸。甲看见纸角印着的官印，是昨日才废的那一枚。 |
| 悬念留白。（无具体物） | 电话响到第四声，甲才接。那头先笑，笑完问：「你还记得湖底那扇门吗？」甲没挂。他从不记得告诉过任何人。 |

## 常见错误

- **假悬念**：吓人但下章无事。
- **泄底**：章末已说明凶手。
- **重复上章钩子**类型无新意。
- **断太早**：高潮未到就断，读者烦。

## 与 AI 出题的关系

题目给本章摘要，要求写章末 50–150 字钩子。评改看：具体性、是否泄底、拽力。

## 延伸练习建议

- 同情节写 3 种断点：人、物、话。
- 删掉最后一句解释，看是否更钩。
