# 转场过渡

## 本节目标

- **时间/地点跳切**不突兀，读者跟得上。
- 交代**必要信息**（过了多久、谁在场），不交代废话。
- 用**感官或动作桥**连接（关门→车轮→到府）。
- 控制过渡长度，忌「与此同时」式灌水。

## 核心概念

转场是剪辑。网文常见：**空行+时间词**、**一物串联**（同一封信从A手到B手）、**声音桥**（钟声未绝，已换场景）。

原则：**跳得省，跳得清**。大跳（三年後）要有信号；小跳（次日）一句即可。

## 怎么做

1. **标时间**：次日、三日后、雨停时。
2. **标地点**：到城南、进宫、回营——一句就够。
3. **留一条线**：同一人物、同一物件、同一未了事。
4. **删路上风景**除非路上有戏。
5. **检查因果**：跳场后人物状态是否合理（伤、衣、情绪）。

**检查清单**

- [ ] 读者是否知何时何地？
- [ ] 是否跳太多信息断层？
- [ ] 过渡是否过长？

## 正反例

| 差 | 好 |
| --- | --- |
| 与此同时，在另一座城市…… | 甲关上门。雪在台阶上积了一层。再开门时，已是春日，门轴响得发涩。 |
| 他走了很久，终于到达。 | 马在渡口嘶鸣。甲甩缰下水，弃马——对岸灯火三点，是寨。 |
| 场景转换到皇宫。 | 碗底还剩一口茶，茶已凉。宫监在门外咳一声：「娘娘，该梳妆了。」 |

## 常见错误

- **硬切无信号**。
- **「与此同时」滥用**。
- **路上游记**：过渡章写旅行无冲突。
- **状态矛盾**：上段重伤下段狂奔无说明。

## 与 AI 出题的关系

题目要求两场景间写 40–120 字过渡。评改看：清晰度、必要信息、是否拖沓。

## 延伸练习建议

- 用同一物件写 A 地到 B 地的 3 句过渡。
- 把 200 字过渡压到 50 字且不丢信息。
