# 喜剧轻松

## 本节目标

- 笑点来自**情境、误会、反差**，少硬梗、网络烂梗堆砌。
- **吐槽**要符合人物嘴型，不是作者讲段子。
- 轻松段也要推事，纯搞笑会水。
- 节奏：压一下再抖，忌连珠梗。

## 核心概念

网文喜剧常是**反差人设+严肃背景的裂缝**：冷面说蠢话、怂人装狠、严肃场合出糗。笑点要**可预期又出乎方式**（读者知会尴尬，但不知怎尴尬）。

忌解释笑点（「这很好笑」）；忌全员相声；忌与残酷剧情_tone_撕裂除非刻意。

## 怎么做

1. **定严肃目标**（谈判、逃亡、拜师）。
2. **插入 1 个错位**（道具、口误、规则误解）。
3. **用正经语气说荒谬话**。
4. **旁人认真反应**增笑感。
5. **收束回到剧情**。

**检查清单**

- [ ] 删掉梗是否还有戏？
- [ ] 是否人物一致？
- [ ] 是否硬梗过多？

## 正反例

| 差 | 好 |
| --- | --- |
| 哈哈哈，太搞笑了。 | 甲郑重拱手：「晚辈愿拜前辈为师。」乙指了指门口扫地的：「那是我师尊。」扫地老头抬眼：「今日不收，昨日收的满了。」 |
| 主角讲了很多网络流行语。 | 乙宣读战书，声震瓦。甲听完，问：「你们军粮带够了吗？」乙一愣。甲：「没带够的话，我可以借你们一点盐。」 |
| 喜剧就是乱开玩笑。 | 刺客落地，刀寒。甲把茶杯递过去：「先喝口热的，你手抖。」刺客：「……」甲：「抖成这样，砍不中我，白来。」 |

## 常见错误

- **作者跳出来搞笑**。
- **烂梗/date梗**易过时。
- **贬智降格**：把反派写成傻子只为笑。
- **连续梗无剧情**。

## 与 AI 出题的关系

题目给严肃场景插入轻松段或写误会。评改看：情境、反差、人设、是否硬梗。

## 延伸练习建议

- 80 字紧张场景里加 1 句冷幽默，不许「哈哈」。
- 用「正经语气」写荒谬请求。
