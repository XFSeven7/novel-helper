# 心理内心

## 本节目标

- **画面化心理**：用联想、动作、感官外化情绪，少写「他觉得/他想」。
- 控制内心篇幅，网文忌长篇意识流。
- 心理与**当下场景**互动，不是飘在空中回忆大全。
- 限知 POV 下内心要符合人物所知。

## 核心概念

内心戏不是日记，是**读者偷看角色脑内弹幕**。好写法：一个突兀的念头 + 身体反应 + 立刻被外界打断。坏写法：「他心想」接 200 字分析。

用**具体意象**代替情绪词：不说「愧疚」，写「不敢看那只空碗」。闪念宜短，分析宜拆成行动犹豫。

## 怎么做

1. **划掉连续三个「他想到」**，改动作或对话。
2. **一句念头 + 一句外界刺激**交替。
3. **用问句表犹豫**：「若回去，门还开吗？」
4. **禁止全知内心**：角色不能想他还不知道的秘密（除非伏笔梦/猜）。
5. **收束到决定**：想完要接「做或不做」。

**检查清单**

- [ ] 「觉得/心想」是否过多？
- [ ] 是否有可拍画面？
- [ ] 是否脱离当下场景？

## 正反例

| 差 | 好 |
| --- | --- |
| 他觉得非常后悔，想了很久过去的事。 | 空碗还温着。甲伸手又缩回——那晚她也是先走的，没回头。门外脚步响了。 |
| 他心想敌人很强，自己很危险。 | 刀口卷了。乙拇指抹一下刃，没血，只有汗。对面影子又近半步。 |
| 内心充满矛盾与挣扎。 | 签还是撕。纸边在汗里软了。甲抬眼，堂上那盏灯晃一下，像催。 |

## 常见错误

- **告知式内心**：「他很难过」。
- **作者说教**：借角色嘴讲道理。
- **无限回忆**：内心触发 800 字闪回。
- **人人读心**：无依据猜他人想法。

## 与 AI 出题的关系

题目常给：抉择前、恐惧时、撒谎时的心理外化。评改看：画面化、少「觉得」、是否贴场景。

## 延伸练习建议

- 80 字写犹豫，禁止「想、觉得、心中」。
- 把一段内心独白改成 3 个动作。
