# 质问审讯

## 本节目标

- 写出**问答攻防**：问的人逼、答的人躲或反制。
- 避免审讯流水账（问一句答一句像填表）。
- 控制**信息释放节奏**：真相一句句挤出来。
- 用环境、道具、第三人打破单调。

## 核心概念

审讯戏本质是**信息不对称的拔河**。问方要布局（诈、吓、诱）；答方要策略（装傻、半真、反咬）。网文里公堂、密室、灯下审问都适用。

好审讯 = **问题有刀** + **答案有缝**。每个问题要么逼对方撒谎（留后手），要么逼对方暴露习惯。

## 怎么做

1. **定问方真正想知道的 1 件事**。
2. **设计 3 层问题**：外围 → 核心 → 诈唬验证。
3. **答方每次只给 70% 真**：留矛盾供后面翻。
4. **插入打断**：咳嗽、狱卒进门、证据摔桌上。
5. **用细节代替「他慌了」**：喉结、语速、视线落点。

**检查清单**

- [ ] 是否像攻防而非采访？
- [ ] 信息是否逐步释放？
- [ ] 有无连续五问五答无动作？

## 正反例

| 差 | 好 |
| --- | --- |
| 「你是谁？」「我是张三。」「为何来此？」「办事。」 | 「子时你在哪？」甲问。乙：「睡觉。」甲把鞋扔桌上：「泥是城西的。你睡梦里去的？」 |
| 审讯进行了很久，他终于招了。 | 乙第三次说「不认识」时，声音比前两次轻。甲没抬头：「那这封信的笔迹，你教过他？」 |
| 甲非常严厉地审问他。 | 甲把灯芯拨亮一点：「你想清楚，招，是坐板凳；不招，是站板凳。」乙盯着灯影，没说话。 |

## 常见错误

- **问方全知**：还没审就知道答案，像走流程。
- **答方突然全招**：无铺垫崩溃。
- **只有对话无空间**：不写灯、铁链、回声。
- **法律台词堆砌**：不像故事像法条。

## 与 AI 出题的关系

题目常给：公堂、黑屋、战后审俘虏等。评改看：攻防、节奏、信息控制、是否流水账。

## 延伸练习建议

- 写 8 问 8 答，答方每句都比上一句多泄露 5% 真相。
- 加入一次「诈唬失败」让问方改策略。
