# 绝境脱身

## 本节目标

- 写出**紧迫感**：时间、伤势、资源都在减少。
- **取舍明确**：丢什么、牺牲什么、赌什么。
- **最后一搏**有逻辑闭环，不靠机械降神。
- 脱身后让读者感到「侥幸」而非「理所当然」。

## 核心概念

绝境脱身 = 追逐的**高潮版**：选项更少、代价更大。常见结构：看似无路 → 发现伏笔（旧钥、暗道、盟友迟来）→ 付代价逃出。

网文要**提前埋**可用手段，脱逃时一笔带过，读者恍然大悟。临时神仙救场会被骂。

## 怎么做

1. **列当前资源**：伤、刀、距离、帮手、时间。
2. **写「错招」或「险招」**：引爆炸药、跳河、装死。
3. **代价落地**：失血、暴露身份、失去道具。
4. **用倒计时**：门合拢、水淹、毒发。
5. **结束在「还没安全」**：逃出牢笼仍在追捕中，保持张力。

**检查清单**

- [ ] 脱身手段是否前文可接受？
- [ ] 是否有代价？
- [ ] 是否无敌/无逻辑？

## 正反例

| 差 | 好 |
| --- | --- |
| 关键时刻他爆发了，逃走了。 | 甲把最后一口酒泼向火盆，火舌扑向追兵脸；他趁乱滚进排水沟，沟壁割破后背，顾不得。 |
| 绝境中他非常冷静，顺利逃脱。 | 乙数到三，第三下不是跑，是把同伴推上绳梯——自己没上。绳梯晃断一根，他挂在崖草里，草在拔根。 |
| 神秘人救了他。 | 甲咬破袖口塞耳，跳湖。冷透前浮起，岸边是昨日埋的筏——昨日若没埋，今日死。 |

## 常见错误

- **机械降神**：从未提及的能力/人物。
- **零代价**：全身而退。
- **解释过长**：逃命时还科普。
- **紧迫感假**：有闲心描写风景。

## 与 AI 出题的关系

题目常给：牢笼、悬崖、火场、包围圈。评改看：紧迫、取舍、逻辑、代价。

## 延伸练习建议

- 列 3 种脱身法，选最伤人的一种写。
- 脱身后用 2 句写「仍未安全」。
