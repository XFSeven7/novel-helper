# 分手决裂

## 本节目标

- 写**不可挽回**或**当下决裂**的瞬间，有明确爆发点。
- 台词**带伤害**，但避免狗血台词堆砌（「你从来没有」循环）。
- 情绪有**因果**：决裂因具体事，不是突然发疯。
- 用物件、动作定格（戒指、钥匙、转身关门）。

## 核心概念

分手戏要**切断未来**：不是「我们冷静一下」的模糊，而是读者感到「这条线断了」。网文常用：当众羞辱、发现背叛、原则冲突、生死立场对立。

结构：**压 → 揭 → 判 → 走**。最后一句话或动作要冷、要干净，忌双方哭喊十分钟无新信息。

## 怎么做

1. **定不可调和点**（只选 1 个核心的）。
2. **第三回合揭短或揭证据**。
3. **写 1 个象征动作**：摘镯、划名、撕纸。
4. **一方先结束对话**（挂电话、推门）。
5. **删「永远」「恨你」复读**，换成具体指控。

**检查清单**

- [ ] 读者是否相信「回不去了」？
- [ ] 是否有具体事由？
- [ ] 是否狗血空喊？

## 正反例

| 差 | 好 |
| --- | --- |
| 「我恨你！」「我也恨你！」十遍。 | 「孩子是你的吗？」甲问。乙沉默。甲点头：「好。门我不锁，你今晚走。」 |
| 他们分手得很伤心。 | 乙把钥匙放在桌上，金属碰瓷盘，一声脆响。甲没抬头：「拿走。明天账房会结清。」 |
| 场面非常感人，读者都哭了。 | 甲笑了一下，把婚书折成两半，不是撕，是折，折得很慢：「从此别叫我妻。」 |

## 常见错误

- **无铺垫决裂**：前文还甜，下一句离婚。
- **全员歇斯底里**：信息量不增。
- **说破所有伏笔**：分手章变成解释大会。
- **立刻复合无代价**（除非类型恶搞）。

## 与 AI 出题的关系

题目常给：情侣、师徒、合伙人决裂。评改看：爆发点、因果、台词杀伤力、是否狗血。

## 延伸练习建议

- 用 120 字写完决裂，最后一句不超过 10 字。
- 写「冷静分手」版，禁止提高音量。
