# 觉醒升级

## 本节目标

- 写出**突破/新能力首秀**的力量感与新鲜感。
- 明确**代价与限制**（耗命、冷却、反噬、只能一次）。
- 避免无敌感：升级后仍有威胁或新问题。
- 升级与情绪/剧情节点绑定（被逼到绝境、护人、誓言）。

## 核心概念

升级是**读者付费点**的情绪回报。要有「之前不行 → 现在行了」的对照。首秀写**一个清晰动作**胜过十个新名词。

结构：**压到极限 → 触发（情、伤、物）→ 身体/天地反应 → 一招见效果 → 代价显现**。

## 怎么做

1. **写升级前最后一次失败**。
2. **触发要具体**（不是「潜力爆发」）。
3. **首秀只秀 1 个核心能力**。
4. **立刻用敌人/环境验证**。
5. **写代价**：晕、裂、旧伤复发、被盯上。

**检查清单**

- [ ] 是否有对照？
- [ ] 是否有代价/限制？
- [ ] 是否名词堆砌无画面？

## 正反例

| 差 | 好 |
| --- | --- |
| 他突破了，变得无比强大。 | 甲丹田像被针扎穿，他咳出血，血里有金线。下一掌推出，墙灰一颤，乙护体罡碎成雨。甲跪下去，掌心血泡冒。 |
| 觉醒了很多新技能。 | 只一件事：甲听见了十步外的心跳。他抬手，刀从乙鞘里滑出半寸——然后甲鼻血涌下，世界又聋了。 |
| 升级后无人可敌。 | 阵亮了。甲站起，只多站了三息，阵光就暗。乙没退：「三息，够我杀你四次。」甲笑，血从齿缝出来。 |

## 常见错误

- **无铺垫升级**。
- **无敌无代价**。
- **说明书式境界名**。
- **升级后不改变局面**。

## 与 AI 出题的关系

题目常给：绝境突破、血脉觉醒、系统奖励首秀。评改看：对照、代价、画面、限制。

## 延伸练习建议

- 写升级 120 字，必须含 1 个代价句。
- 首秀只用一个动词描写效果。
