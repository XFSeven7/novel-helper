# 谈判博弈

## 本节目标

- 写出**双方都有筹码**的谈判，不是一方说教一方点头。
- 掌握**交换、施压、留白**：话说七分，留三分逼对方猜。
- 信息**不说破**：价码、底线、底牌用暗示和试探。
- 每轮对话改变力量对比或局面。

## 核心概念

谈判戏是**静态打斗**：输赢看谁先露底、谁先慌。网文常见：商会、宗门、官场、情侣分财产。好的谈判 = 明面客气 + 暗地刀光。

结构：**开价 → 还价 → 掀一张牌 → 僵局 → 妥协或翻脸**。要有「若你不答应，我将如何」的隐含威胁，不必写满。

## 怎么做

1. **列双方要什么、怕什么**（只给自己看）。
2. **设计 2 次假让步、1 次真底线**。
3. **用具体数字/条件**，少用「差不多」「可以考虑」。
4. **沉默也是台词**：「……」+ 看表、喝茶、起身作势要走。
5. **第三者或时限**增加压力（门外脚步声、合同倒计时）。

**检查清单**

- [ ] 双方是否都有合理筹码？
- [ ] 是否有「说破」的句子可删？
- [ ] 谈完局面是否和谈前不同？

## 正反例

| 差 | 好 |
| --- | --- |
| 「你要什么？」「我要钱。」「好。」 | 「三成。」乙说。甲笑：「一成，外加你城南那家铺子的账。」乙指尖停了一下：「两成。账你自己查。」 |
| 他们谈了很久， finally 达成协议。 | 甲推过茶：「喝口热的再签。」乙没碰：「条款第七条，你改一个字，我改一个字。」 |
| 甲威胁乙如果不答应就完蛋。 | 「明日辰时，衙门的卷宗就归档了。」甲擦杯口，「归档前，还能改一个字。」 |

## 常见错误

- **一方弱智**：反派只会「我不给」。
- **底牌第一章就亮完**。
- **只有嘴炮无代价**：答应了却不影响后文。
- **书面合同腔**：不像人说话。

## 与 AI 出题的关系

AI 常出：商业谈判、赎人、宗门资源分配等。评改看：筹码、留白、交换是否清晰、是否说破。

## 延伸练习建议

- 写 10 轮谈判，禁止出现「成交」二字，最后用动作表示成交。
- 给双方各加一条「不能公开的弱点」，谈判中各用一次。
