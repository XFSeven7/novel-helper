## 本节目标

- 能识别毛病稿中的告知体、长句拖沓、弱对话、无推进。
- 改稿后保留核心冲突，提升节奏、画面与对话功能。
- 在字数限制内精炼，不另起新剧情。

## 核心概念

综合改稿是前几类技能的**集成考试**：不是再加华丽辞藻，而是让读者更快、更清楚地体验同一场戏。改稿目标：

- 情绪用展示；
- 快场用短句；
- 对话有冲突或信息差；
- 删掉无功能句。

## 怎么做

1. **先标问题类型**：告知 / 节奏 / 对话 / 结构，各用不同刀法。
2. **保留事件链**：谁对谁做了什么不能变，变的只是写法。
3. **先删后加**：优先删赘词与重复，再补感官锚点。
4. **对照原文长度**：题目若限 450 字，改后勿超标。

**检查清单**

- [ ] 是否还有「很××」？
- [ ] 长句是否已拆？
- [ ] 对话是否推动局面？
- [ ] 是否比原文更好读？

## 正反例

| 差（毛病稿） | 好（改稿方向） |
| --- | --- |
| 他非常生气，大声骂了对方一顿，说了很多难听的话。 | 「出去。」他声音不大。 对方却退了半步——因为桌角那张纸，已经盖了印。 |
| 场面很乱，大家跑来跑去，情况十分紧急。 | 警报还在响。 乙拽住甲的袖子：「北门堵死了。」 |

## 常见错误

- **改剧情**：为了好看换了结果，练习判为跑题。
- **只改措辞不换结构**：烂骨架上贴金。
- **越改越长**：精炼是本分。
- **丢掉核心冲突**：改顺了但不知道在吵什么。

## 与 AI 出题的关系

题目常给 150–300 字毛病稿，要求改稿或压缩。严师按综合维度从严；70 分及格。

## 延伸练习建议

- 自写一段毛病稿，隔一天再改，对比两次得分（若已评改）。
- 同一毛病稿改两版：一版偏节奏，一版偏画面，看哪版更适合网文扫读。
