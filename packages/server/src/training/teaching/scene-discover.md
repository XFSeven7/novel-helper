# 发现线索

## 本节目标

- 写**发现过程**：找、翻、误触、对比，不是作者直接告诉。
- **主角反应**具体（停手、吸气、四顾）。
- 线索可验证、可误读（真线索/假线索）。
- 发现后改变下一步行动。

## 核心概念

发现戏是悬疑/探险的**齿轮**。读者要跟主角一起「哦」。好发现 = **动作链 + 感官 + 结论半句**。

结构：**寻找动机 → 障碍（锁、尘、时间）→ 触发（光、味、字）→ 反应 → 决定带走/报告/隐瞒**。

## 怎么做

1. **写为什么要找**（一句）。
2. **写 2 个搜索动作**（移物、照光）。
3. **线索要具体**（缺角的印、未干的墨、异香）。
4. **写身体反应**先于分析。
5. **留一半信息**下章再解。

**检查清单**

- [ ] 是否有过程？
- [ ] 线索是否具体？
- [ ] 发现后是否有行动变化？

## 正反例

| 差 | 好 |
| --- | --- |
| 他发现了重要线索。 | 甲拂开灰，砖缝里有新泥。新泥里嵌半片指甲，染蔻丹——城里只有掌柜娘子涂这色。 |
| 密室里有尸体和宝藏。 | 乙举火折，光扫到墙绘，绘的是门。门的位置，正是他背靠的这面「墙」。他退开，砖温的。 |
| 他震惊不已。 | 信纸边有齿痕，小，像孩童。甲把信凑近烛，齿痕旁还有一点糖渍——昨日失踪的，是孩。 |

## 常见错误

- **无过程直接结论**。
- **线索太明显/太玄**。
- **发现无后果**。
- **主角全知搜索**（没翻就知）。

## 与 AI 出题的关系

题目给密室、遗物、案发现场等。评改看：过程、线索质量、反应、后续推动。

## 延伸练习建议

- 写发现 100 字，禁止「发现」「震惊」。
- 设计一条可误读的假线索。
