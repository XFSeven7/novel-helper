# 惊悚压迫

## 本节目标

- 用**未知、压迫、安全感剥夺**制造惊悚，少血浆堆砌。
- **悬念维持**：不早揭鬼/凶手全貌。
- 感官选 1–2 个通道深挖（声、触、暗）。
- 人物反应要具体（僵、退、自欺）。

## 核心概念

惊悚 = 读者脑补比作者描写更可怕。网文宜**慢进快出**：压迫累积 → 短释放 → 更大未知。

技巧：**正常里的歪**（钟走对、脚步声多一步）、**规则**（别回头、数到十）、**限知**（只听见不见）。

## 怎么做

1. **先写安全假象**一小段。
2. **插入 1 个不对**的细节。
3. **重复或递进**（再响一次，更近）。
4. **少解释原因**，保持未知。
5. **断在威胁未解除**。

**检查清单**

- [ ] 是否过早揭底？
- [ ] 是否只靠血浆？
- [ ] 是否有具体感官？

## 正反例

| 差 | 好 |
| --- | --- |
| 很恐怖，血到处都是。 | 灯芯没灭，墙影却多了一条。甲数：一张床，两把椅，三个影。他退半步，第三个影没退。 |
| 鬼出现了，长得很吓人。（详写鬼脸） | 门缝在渗风，风里有湿土味。甲问：「谁？」回答从床底来，贴着他脚踝：「你。」 |
| 惊悚氛围浓厚。 | 更鼓敲到第五下，停了。甲才发现，鼓声停之前，有人在他耳边数：「四。」 |

## 常见错误

- **血腥代替惊悚**。
- **鬼脸说明书**。
- **主角智商下线**硬送。
- **无悬念揭底**一章讲完。

## 与 AI 出题的关系

题目给老宅、夜路、密室等。评改看：未知、压迫、悬念、感官、少血浆。

## 延伸练习建议

- 100 字惊悚，不出现「鬼、恐怖」。
- 用「多数一数不对」写压迫。
