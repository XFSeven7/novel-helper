# 天气时辰

## 本节目标

- 写出**雨夜、雪晨、酷暑、大雾**等清晰时段感，读者知道「什么时候」。
- 让天气**参与叙事**（阻碍行动、放大情绪、成为道具），不是背景壁纸。
- 避免不经加工的成语式天气（「电闪雷鸣」一串带过）。
- 天气与人物身体感受挂钩（冷、黏、喘、睁不开眼）。

## 核心概念

天气是网文最便宜的**节奏开关**：暴雨困住追兵、大雪封路逼出选择、酷暑让人暴躁易冲突。好的天气描写 = **时辰 + 身体 + 一件具体事**。

读者对天气有类型记忆：修仙文里雷雨常伴突破；悬疑里雾藏线索。可以反用——大晴天办丧事，反差本身就有戏。

## 怎么做

1. **选定一种主天气**，别雨夹雪夹雹全上。
2. **写身体反应**：雨灌进领口、雪进靴筒、暑气堵在喉咙。
3. **让天气挡一件事或帮一件事**：路滑摔了、雷声盖过脚步声、烈日晒化证据。
4. **用一个非常规细节**：不是「雨很大」，而是「雨点先砸在铁皮棚上，像有人撒豆子」。
5. **控制陈词**：慎用「瓢泼」「鹅毛」；换成你看见的。

**检查清单**

- [ ] 读者能否判断大致时辰与季节？
- [ ] 天气是否影响了人物行为？
- [ ] 是否至少 1 个非套话细节？

## 正反例

| 差 | 好 |
| --- | --- |
| 外面下着倾盆大雨。 | 雨斜着打，伞骨咔一声翻过去；甲把包顶在头上，跑过街口时水没到脚踝。 |
| 天气很热。 | 柏油软了，鞋底拔起来带丝；乙眯着眼看远处，热浪把街口的招牌扭弯。 |
| 雪下得很大，很美。 | 雪先占住肩线，再走一步，靴底和石阶发出干涩的摩擦；门环上积了一层，敲下去没有声。 |

## 常见错误

- **天气与情节无关**：下了一章雨，谁都能干的事照样干。
- **套话堆砌**：「狂风暴雨」「大雪纷飞」无具体画面。
- **只有天空没有地面**：不写积水、泥泞、反光、室内对比。
- **气候突变无铺垫**：刚才晴空万里，下一句暴雪。

## 与 AI 出题的关系

AI 常指定：雨夜对峙、雪晨送别、酷暑赶路等，要求天气推动画面。评改看：时段感、是否参与叙事、陈词滥调、感官是否落地。

## 延伸练习建议

- 同一事件写两遍：晴天版 vs 暴雨版，看冲突感变化。
- 用 50 字只写「热」，禁止「炎热」「酷暑」二字。
