# 抄书 · 机械输入期

## 本节目标

- 通过逐字临摹，把阅读语感转化为写作时的句法节奏。
- 关注标点位置、段落长短与排版，而非情节构思。
- 先求「手熟」，再进入拆书与画面感训练。

## 核心概念

抄书不是抄袭，而是**认知卸载**：你不需要想「接下来写什么」，只需感受原文的句长错落、标点停顿和用词组合。手指跟读的节奏会在重复中形成肌肉记忆。

## 怎么做

1. **导入 txt**：选一本想模仿的作品，按章节切分后逐章练习。
2. **对照抄写**：左栏原文可按需微调排版（分段、删冗余）；右栏逐字输入。
3. **保留格式**：换行与段落会原样保留，便于观察作者如何切段。
4. **完成本章**：抄完点「完成本章」标记进度，可随时断点续抄。

## 检查清单

- [ ] 是否注意到对话与旁白的段落差异？
- [ ] 标点是否随节奏变化（快场短句、慢场长句）？
- [ ] 是否能在抄写中感受到句子的呼吸感？

## 常见错误

- **边抄边改剧情**：机械期只临摹，不改内容走向。
- **求快不求稳**：宁可慢，也要把标点与分段抄准。
- **跳过标点**：标点是节奏的一部分，不可省略。
