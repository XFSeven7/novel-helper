# 抄书练习 · 机械输入期

## 本节目标

- 通过**靶向、慢速**的逐字临摹，把成熟文本的语感内化为自己的句法节奏。
- 关注标点、段落、句长与用词组合，暂时卸载「接下来写什么」的情节负担。
- 为后续的拆书、画面感与句式专项训练打好肌肉记忆。

## 核心概念

抄书不是抄袭，而是**认知卸载**：写作时大脑同时要处理情节、句法和用词，新手容易过载卡顿。临摹时你只跟读原文，让注意力落在微观质感上——句长错落、标点停顿、动词与名词的选择。

参考「文笔提示核心手段」：**不必盲目通篇硬抄整本书**。更划算的做法是像用显微镜一样，针对自己的薄弱环节（对话干、动作扁、环境空），专门找出标杆作品里**对应类型的成功段落**来抄，体会作者如何切换视角、如何分配对话与旁白。

## 在本工具里怎么做

1. **导入 txt**：选一本欣赏其文笔的书，按「第 X 章」切分后逐章练习；若无章节标题则整本作为单章。
2. **左栏原文**：可微调排版（分段、删冗余）；需要时点 **「排版」** 做本地分段与段首空位，便于观察网文式短段落。
3. **右栏抄写**：逐字输入，换行与段落尽量与左栏一致；内容**自动保存**，可随时断点续抄。
4. **先慢后快**：宁可慢，也要把标点与分段抄准；速度是肌肉记忆形成之后的事。

## 抄写时建议关注的点

对照原文抄写时，心里可以挂这几条（不必另开笔记，观察即可）：

- **动词与名词**：哪些是精确动词？哪些形容词其实可以省掉？
- **句式与节奏**：快场是否短句连打？慢场是否长句铺陈？
- **对话与旁白**：段落如何切分？话在前、动作插话如何排版？
- **视角切换**：外部微表情与内心活动如何交替？

若某类场景总是写不好，回到目录换章节，**只抄同类场景**直到有手感，再换下一项短板。

## 检查清单

- [ ] 是否针对自己的薄弱场景选段，而不是无差别通抄？
- [ ] 对话与旁白的段落差异是否抄出来了？
- [ ] 标点是否随节奏变化（快场短句、慢场长句）？
- [ ] 抄写过程中能否感到句子的「呼吸感」？

## 常见错误

- **边抄边改剧情**：机械期只临摹，不改内容走向。
- **求快不求稳**：标点、分段抄错，后面的语感全是歪的。
- **跳过标点**：标点是节奏的一部分，不可省略。
- **只抄情节高潮**：日常对话、过渡、环境往往才是笔力的底盘，别只挑爽点抄。

## 进阶方向（完成机械期之后）

同一套「文笔提示」里，机械抄写熟练后可衔接：

- **分析解码**：抄时带着问题——这句为何用这个动作词？若换成你会怎么写？
- **富兰克林式重写**：把段落提炼成几个关键词，隔几天凭关键词自己重写，再与原文逐句对比。
- **长短句实验**：同一画面先用长句写一遍，再用短句写一遍，感受心率与潜台词的变化。
- **极简剪裁**：旧稿强行删 25% 字数，练「去掉五个字 / 五个句子」的含金量。

这些可在「文笔技法」其他分类与场景练习中继续深化；抄书练习先把**输入端的语感**练到手熟。
