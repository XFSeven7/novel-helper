# 暧昧亲密

## 本节目标

- 用**距离、动作、停顿**写暧昧，少直说「喜欢」「心动」。
- **克制**不油腻：暗示多于表白，留白多于说满。
- 细节要**可演**：指尖、呼吸、避开的视线、故意的碰触。
- 暧昧要有**阻碍**（身份、危险、误会），否则只是甜腻。

## 核心概念

网文暧昧靠**差一点**：差一寸碰到、差一句说破、差一步越界。读者追的是「会不会」而不是「我爱你」三连。

写身体时用**小动作链**：递东西时指尖相触 → 各自收回 → 话题变轻。忌大段肉体描写除非类型需要；言情重氛围，玄幻重张力。

## 怎么做

1. **定两人此刻各怕什么、各要什么**。
2. **选 2 个距离动作**：并肩走、递伞、帮系带子。
3. **写一次「差点说破又收回」**。
4. **用环境衬**：雨声、电梯停层、旁人咳嗽。
5. **禁止「心动」「小鹿乱撞」**，改生理小反应。

**检查清单**

- [ ] 是否零「爱/喜欢」直球（除非类型允许）？
- [ ] 是否有具体动作细节？
- [ ] 是否油腻或全员霸总腔？

## 正反例

| 差 | 好 |
| --- | --- |
| 他觉得她很美，心动了。 | 乙递过帕子，甲接时慢了半拍，帕角在两人指间停了一瞬，乙先松手。 |
| 他们暧昧地聊了很久。 | 「你再靠近，」甲看着窗玻璃里的影子，「我就喊人。」乙停住，笑：「你喊。」没动。 |
| 气氛很浪漫。 | 烛芯爆了个花，两人都看向别处；甲把杯沿转了一圈，乙才伸手盖住杯口：「别喝了。」 |

## 常见错误

- **告知式甜蜜**：「甜蜜的氛围」「怦然心动」。
- **无阻碍直给**：认识三章就搂抱，张力归零。
- **性别刻板动作堆砌**。
- **与 POV 脱节**：单视角却写对方内心。

## 与 AI 出题的关系

题目常给：雨夜共伞、疗伤上药、宴会擦肩等。评改看：克制、细节、潜台词、是否油腻。

## 延伸练习建议

- 100 字暧昧，禁止「爱、喜欢、心动」。
- 同场景写「想靠近」与「必须推开」两个版本。
