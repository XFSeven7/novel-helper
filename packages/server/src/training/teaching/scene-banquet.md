# 宴会饭局

## 本节目标

- 写出**座次、敬酒、话里有话**的社交戏。
- **暗流**大于菜色：谁敬谁、谁先动筷、谁被孤立。
- 用宴席道具：杯、筷、汤、屏风后人。
- 信息通过敬酒词、贺词、当众问话传递。

## 核心概念

饭局是**低成本权力场**。上座、主敬、替酒、摔杯都有戏。网文常用：认亲、逼婚、投毒、当众羞辱、结盟。

结构：**入席定规矩 → 三轮酒话交锋 → 变故（毒、刺客、圣旨）→ 散席余波**。

## 怎么做

1. **画座次**（主、客、辱、护）。
2. **写 1 个座位细节**（空椅、薄垫、背对门）。
3. **敬酒带刺**：贺词双关。
4. **插入菜/汤动作**打断对话。
5. **屏风、侍女、奏乐**作信号。

**检查清单**

- [ ] 座次/权力是否可读？
- [ ] 是否有社交信息？
- [ ] 是否只有吃菜描写？

## 正反例

| 差 | 好 |
| --- | --- |
| 宴会很热闹，大家喝酒聊天。 | 主位空着，酒杯却满。甲入座末席，筷尖先碰汤碗——试毒老习惯。乙举杯过来：「敬未来东家。」甲没站：「东家未到，这杯算敬谁？」 |
| 他们在宴会上谈判成功。 | 第三巡，乙把蟹钳敲碟边，三下。屏风后有人咳。甲抬眼，主位仍空，门却开了。 |
| 饭菜很丰富，描写很多。 | 全桌等甲先动筷。甲夹了一筷青菜，放下：「菜齐，人不齐。缺的那位，在牢里还是在路上？」 |

## 常见错误

- **菜谱式描写**。
- **无座次权力**。
- **酒话直白无刺**。
- **变故无铺垫**。

## 与 AI 出题的关系

题目给家宴、庆功、鸿门宴等。评改看：座次、暗流、话里有话、社交信息。

## 延伸练习建议

- 写敬酒 4 句，句句带刺，不许脏字。
- 用空椅写权力真空 60 字。
