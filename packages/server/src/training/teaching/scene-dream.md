# 梦境幻觉

## 本节目标

- **边界清晰**：读者知道在非现实段落，醒后落点明确。
- 用**错位、象征、变形**服务主题，不是随机怪谈。
- 梦境宜短，承担预示或心理外化。
- 幻觉与 POV 一致（中毒、重伤、心魔）。

## 核心概念

梦/幻觉是**合法的超现实**，但要省着用。网文里梦常用于：预告危机、暴露欲望、类型文「秘境试炼」。

写法：**违和细节**（门无限长、人脸空白、声音滞后）比全面怪诞更有效。醒来用感官拉回：冷、疼、有人摇肩。

## 怎么做

1. **入场信号**：睡意、药、伤、阵法。
2. **梦内 1–2 个重复意象**（水、绳、红）。
3. **逻辑故意歪**：墙走、话倒放。
4. **惊醒动作**：弹坐、呕吐、掐自己。
5. **醒后 1 句对照现实**，确认真假。

**检查清单**

- [ ] 能否分清梦/醒？
- [ ] 是否有功能（非纯炫技）？
- [ ] 是否过长拖主线？

## 正反例

| 差 | 好 |
| --- | --- |
| 他做了一个很长的梦，梦里很多事。 | 走廊没有尽头。每扇门后都是同一张桌，桌上空碗。甲跑，脚不沾地——醒时真的在喘，枕巾咬在嘴里。 |
| 梦境非常奇幻玄妙。 | 乙说话，嘴动迟半拍。甲伸手，手穿过乙肩。他低头，自己手腕系着红绳，绳另一头系在棺木上。棺木在摇，像船。 |
| 醒来后继续写梦的内容当真的。 | 甲睁眼，帐顶绣鹤还在。他摸颈侧，汗冷。门外真实的更鼓敲了一下，他才算回来。 |

## 常见错误

- **梦=随意堆砌**符号。
- **醒后无落点**。
- **用梦硬补坑**（读者不买账）。
- **与类型冲突**：写实文突然长篇神梦。

## 与 AI 出题的关系

题目常给：心魔、预知、中毒幻觉等。评改看：边界、象征、长度、醒后落点。

## 延伸练习建议

- 梦 100 字，醒 2 句，禁止解释梦寓意。
- 用重复意象写「不安」不写「害怕」。
