# novel-helper 项目

这是由 `novel-helper init` 生成的本地写作项目。

## 启动

```bash
pnpm install
pnpm dev
```

- UI: `http://127.0.0.1:5177`
- Server: `http://127.0.0.1:3177`

## 目录结构

- `book/<bookSlug>/chapters/*.md`：章节
- `book/<bookSlug>/story/characters/*.md`：角色卡（每个角色一个文件）
- `book/<bookSlug>/story/*.md`：时间线、世界观、状态、大纲等
