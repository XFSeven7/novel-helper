# novelHelper

在自己电脑上写长篇用的网页小工具。打开浏览器就能写章节、记设定、做分析，字都会自动存到本地文件夹里，不依赖网盘账号。

---

## 怎么跑起来

1. 装好 Node.js，用 pnpm 安装依赖：

```bash
pnpm install
```

2. 启动：

```bash
pnpm dev
```

3. 浏览器打开：**http://127.0.0.1:5177**

后台服务会在本机 `3177` 端口跑，一般不用管。改完代码若页面没刷新，可在项目根目录执行 `pnpm dev:restart` 重启一次。

## 能干什么（按使用场景）

### 写正文

- 书架里新建或打开一本书。
- 左边选章节，中间写正文，会自动保存。
- 顶栏可以全屏；左右栏可以收起。
- 需要的话可以给章节**存历史稿**，以后对照或还原。

### 开书前先规划

- 书架上方有 **「新书规划」**：按步骤填梗概、主线阶段等，也可以让 AI 帮忙想（要先在设置里配好模型）。
- 可以同时进行多条规划，定稿后再真正「创建书籍」。
- 书建好后，还能 **回顾 / 继续** 当初的规划，并同步到简介、大纲里。

### 大纲

- 左边 **「大纲」** 页：写全书梗概、分卷、章纲、主线阶段。
- 支持用 AI 做扩写、反推、章纲、伏笔检查等（需模型）。

### 随手备注

- 打开书后，左边有 **「备注」** 页。
- 像多个笔记本，默认有一个叫「规划」的，不能删；可以自己加标签页。
- 下面输入框打字，**Enter 保存**，**Shift+Enter** 换行；可以置顶、排序、改标签名；编辑模式下能删笔记本（里面还有字时要先清空或迁走）。

### 设定与灵感

- **全局信息**：角色、地点、组织等（很多来自章节「审计」后的整理）。
- **灵感库**：记名字、设定碎片，可进回收站。
- **进行中**：看当前还有哪些审计相关的事没做完。
- **统计**：今天写了多少、热力图、停更提醒等。

### 单章工具

- **本章分析**：让 AI 读当前章并流式输出结论；换章看别的不会打断正在跑的分析。
- **审计模式**：正文里高亮人物、地点等，点一下能跳到右侧详情。
- **纠错 / 调整**：纠错对照改错别字、标点与语法；调整用于增删字数。满意后一键替换正文。
- **时间线**：每章摘要、多章压成一段摘要、事件打勾完成等。

### 设置

- **模型**：填各家 AI 的接口（含 Ollama 本地），测试通过才能用分析、纠错、规划等功能。
- **数据目录**：书存在哪个文件夹；可以换路径，也可以把整个文件夹迁到新位置（新文件夹必须是空的）。

---

## 书存在哪里

默认在仓库里的 `book/` 文件夹。也可以在 **设置 → 数据目录** 改成别的盘符路径。

每本书一个子文件夹，里面有：

- 章节（`.md` 正文）
- 简介、角色卡、世界观等资料
- 大纲、备注、审计记录、写作统计等

换电脑时，拷贝整个数据目录即可。
