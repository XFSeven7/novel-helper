# novelHelper

本地写小说的网页助手：在浏览器里管理书籍、章节与设定，内容自动保存为电脑上的 Markdown 文件。

## 功能概览

### 写作与资料

- **书架**：新建/打开书籍；查看书籍简介；显示缺失章节序号并支持补齐。
- **章节编辑**：在网页中直接编辑章节正文（自动保存到本地 Markdown 文件）。
- **资料卡（story）**：管理全书资料（包括角色卡文件等），同样落盘为 Markdown。
- **写作统计看板**：左栏「全局信息 → 统计」查看日更字数、写作频率热力、章节长度与累积字数趋势；停更 3 天以上会有提醒。
- **全屏**：顶部支持全屏切换；左/右栏可收起。

### 设置

顶栏 **设置**（齿轮图标）进入，包含两个 Tab：

- **模型**：配置 AI 连接（OpenAI / DeepSeek / Gemini / 千问 / Ollama / 自定义等），测试通过后可用于分析、审计、润色、扩写等。
- **数据目录**：指定 **书籍保存地址**（写作数据根目录）。可浏览选择文件夹；修改并保存时可选择将现有数据 **迁移** 到新的空文件夹，保存后 **立即生效**，无需重启。可选在迁移成功后删除原目录。

### 分析 / 审计 / 内容整理

- **本章分析（流式）**：对当前章节进行 AI 分析（SSE 流式输出）。
  - **5 步进度提示**：展示当前执行到第几步（避免误以为卡住）。
  - **分析不中断**：切换到其他章节浏览时，当前分析不会中断；其他章节会提示「某章正在分析中」，可一键跳回。
  - **分析记录落盘**：分析内容会按章节保存，刷新/切章后可恢复展示。
- **审计阅读模式**：只读渲染正文；对「内容整理对象」（角色/地点/组织/全书记忆事件/资料）做低密度高亮；
  - 悬浮显示对象信息卡片
  - 点击可跳转到右侧内容整理并定位/展开对应对象
- **角色库（全书共享）**：来源于审计结果沉淀，支持隐藏/取消隐藏、编辑角色属性（身份/标签/状态/性格分析）。
  - **搜索（模糊匹配）**：支持按名字/身份/标签搜索；搜索框吸顶常驻。
- **地点库（全书共享）**：来源于审计结果沉淀，支持分组、折叠、隐藏/编辑（描述/发生的事简述）。
- **组织库（全书共享）**：来源于审计事件抽取沉淀，支持隐藏/编辑（描述/动态简述）。

### 时间线

- **每章摘要**：每章审计完成后生成并展示。
- **压缩区间摘要**：可把 N 章摘要压缩成一个区间摘要；支持再次压缩/迭代压缩。
- **事件列表**：支持标记「完成」，可按开关隐藏已完成事件。
- **推荐压缩区间**：AI 会给出适合压缩的章节区间建议。

### 润色与扩写

- **润色（对照）**：一键润色当前章节，编辑区切换为左右对照（左原文/右润色稿），支持「一键更换」；并能标记润色稿中改动片段。
- **快速扩写（对照）**：输入目标字数与补充信息后扩写正文；自动把时间线「压缩摘要」投喂给模型作为上下文；编辑区左右对照（左原文/右扩写稿），支持「一键更换」。

## 开发启动

### 1) 安装依赖

```bash
pnpm install
```

### 2) 启动服务端 + 网页端

```bash
pnpm dev
```

- UI：`http://127.0.0.1:5177`
- Server：`http://127.0.0.1:3177`

## 生产使用（本地运行）

```bash
pnpm install
pnpm build
pnpm dev
```

## 模型配置（AI）

1. 打开顶栏 **设置** → **模型**。
2. 添加提供商并填写 API 信息，点击测试连接。
3. 保存后可用于：分析 / 审计 / 润色 / 扩写 / 时间线压缩等。

**Ollama** 走 OpenAI 兼容 `/v1` 接口，便于稳定流式输出。

## 书籍保存位置

### 默认目录

未配置时，写作数据保存在仓库根目录下的 `book/`：

- `book/<bookSlug>/meta.json`
- `book/<bookSlug>/chapters/*.md`
- `book/<bookSlug>/story/*.md`
- `book/<bookSlug>/story/characters/*.md`（角色卡）
- `book/<bookSlug>/meta/audit/*`（审计与索引）
- `book/<bookSlug>/meta/audit/analysisTexts/*.md`（本章分析文本）
- `book/<bookSlug>/meta/writing-log.json`（写作统计）

全书共用的模型配置保存在数据根目录下：

- `book/_settings/model-configs.json`

### 在应用内修改（推荐）

**设置 → 数据目录**：填写或选择 **书籍保存地址**，点击保存。

- **仅切换目录**：不拷贝文件，直接改用新路径（新目录里可以已有书籍，也可以为空）。
- **迁移数据**：将当前目录下全部内容拷贝到新的 **空文件夹**；可勾选「迁移成功后删除原目录数据」。保存后书架立即刷新，**无需重启** `pnpm dev`。

应用配置写在仓库根目录（不随书籍目录迁移）：

- `.novel-helper/config.json` — 示例：`{ "dataDir": "/Users/you/Documents/my-novels" }`

### 解析优先级

1. 环境变量 `NOVEL_HELPER_DATA_DIR`（最高；设置页中数据目录为只读）
2. `.novel-helper/config.json` 中的 `dataDir`
3. 默认 `<仓库根>/book`

环境变量示例（适合固定目录、脚本启动）：

```bash
NOVEL_HELPER_DATA_DIR="/你的/写作目录" pnpm dev
```

### 写作统计说明

日更字数在每次章节自动保存时按 **正向增量** 累加（删字不会扣减已统计的日更）。首次启用统计时，会把各章当前字数写入基线，不把历史全文一次性算进「今日」。

统计 API：`GET /api/books/:slug/stats`（可选 `?backfill=mtime` 在无日志时用文件修改时间粗估历史日更，误差较大）。

## 项目结构

```
novelHelper/
├── packages/
│   ├── ui/          # Vite + React 前端
│   ├── server/      # Fastify API，读写本地 Markdown
│   └── cli/         # 命令行初始化模板
├── book/            # 默认写作数据目录（可改）
└── .novel-helper/   # 应用配置（本地，已 gitignore）
```

## 常见操作（快速上手）

- **新建一本书**：书架 → 新建书籍。
- **新建章节**：打开书籍 → 新建章节 → 中间栏编辑正文。
- **配置模型**：顶栏 **设置** → **模型**。
- **更改书籍保存位置**：顶栏 **设置** → **数据目录**。
- **本章分析 / 审计**：右侧「本章分析」；正文可开「审计」阅读模式。
- **润色 / 扩写**：章节工具栏 → 润色或扩写 → 对照确认后「一键更换」。
- **写作统计**：左栏「全局信息」→「统计」。
